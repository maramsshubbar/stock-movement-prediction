# Stock Movement Prediction

A Python machine learning project that classifies next-day stock price movements and uses clustering to explore patterns in historical stock data.

The notebook covers data cleaning, feature engineering, and model evaluation. It compares logistic regression, random forest, and gradient boosting for the classification task.

## Run the Notebook

Open `stock_movement_prediction.ipynb` in Google Colab. The notebook expects a file named `Stocks.csv` in Google Drive. The dataset is not included in this repository.
